# Індивідуальний проєкт: Фінансовий трекер студента "FinansManager"

## 🎯 Мета проєкту
Розробка консольної програми на Python для автоматизації обліку особистих фінансів. Бот допомагає студенту контролювати витрати, стежити за лімітом бюджету та аналізувати витрати за категоріями для ефективного керування власними коштами.

## 🧠 Логіка та алгоритм роботи
Програма працює за принципом циклічного опрацювання команд користувача.

**Загальний алгоритм:**
1. **Запуск**: Програма завантажує дані з файлу `finance_data.json`. Якщо файл відсутній — створюється порожня база.
2. **Головне меню**: Бот виводить список доступних команд.
3. **Очікування команди**: Користувач вводить текстову команду (наприклад, "додати витрату").
4. **Виконання**: 
   - Якщо це **"встановити бюджет"**, дані записуються в пам'ять.
   - Якщо це **"додати витрату"**, програма запитує деталі, додає їх до списку та миттєво перевіряє, чи не перевищено ліміт.
5. **Автозбереження**: Після кожної зміни функція `save_data` автоматично оновлює JSON-файл.
6. **Завершення**: Команда "вийти" коректно закриває програму.

## 📊 Структура даних
Для зберігання інформації використовується формат **JSON**, що дозволяє зберігати дані між запусками програми.
- `budget`: Число (float), що зберігає загальну суму бюджету.
- `expenses`: Список (list) об'єктів (dict), де кожен елемент містить:
    - `amount`: сума витрати.
    - `category`: назва категорії.
    - `date`: дата транзакції.
    - `comment`: опис (за бажанням).

## 🛠 Інструкція зі запуску
1. Встановіть **Python 3.x**.
2. Скачайте файл `bot.py` у робочу директорію.
3. Відкрийте термінал або командний рядок у цій папці.
4. Запустіть програму командою:
   ```bash
   python bot.py
